A FEW GOOD QUESTIONS

Before you begin.

Is Little Code a separate app?+

Yes. Little Code ships as its own Electron / Code-OSS desktop application, with a separate product identity, custom navigation, Little Home and Little Agent. The underlying editor is built on Code-OSS.

Does it include free AI usage?+

Cloud inference uses your own Groq key and the provider’s limits. Local inference connects to an Ollama installation you manage. Little does not supply API credits, install Ollama, or pull models automatically.

Can the agent change files without asking?+

Ask and Plan are read-only. Edit and Agent propose changes for native review. You accept or reject file changes, and Agent commands and MCP calls require separate approval. Checkpoints cover accepted file changes, not external side effects of commands.

What can it do with notebooks and documents?+

It reads notebook source cells, DOCX paragraphs, PPTX slide text, and text-based PDF pages. It can propose notebook cell operations and Word/PowerPoint text replacements, create simple documents, append PDF pages, and review whole-file deletions. It does not execute notebooks, perform OCR, or reflow existing PDF content.

Are the language SDKs included?+

The 0.3.0 builder and runner use runtimes you install. Flutter needs an initialized SDK and configured device or web target; Python starters create their own virtual environment. Use Build Tools in the desktop app to discover runtimes or start C/C++ setup.

Where do my chats and credentials go?+

Project chats and memory are saved locally. Groq credentials use encrypted system storage. Cloud requests send selected project context to your chosen provider; local Ollama behavior depends on your engine configuration. This showcase has no signup or analytics; it stores only your appearance preference in this browser.

Is this a finished production release?+

Version 0.3.0 is a development preview. Current source checks, native builder/runner fixtures and setup input hashes are recorded. Live Groq and file-tool evidence belongs to the earlier 0.2 version. Full real-project acceptance, installer lifecycle tests, signing and the complete product roadmap remain in progress.
