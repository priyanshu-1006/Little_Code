# Changelog

This records implemented product changes. Preview availability and supported platforms are stated in the release notes; roadmap items are not presented as delivered features.

## Website — React showcase and field guide

- React 19/TypeScript showcase with 14 pre-rendered routes, responsive light/dark appearances and accessible product walkthroughs.
- Dedicated searchable documentation: 11 guides, real product captures, installation/checksum instructions, navigation and copyable examples.
- Verified GitHub Release download discovery and retained local installer identity/range checks.
- Community ratings, filtering and moderated submissions through a Vercel API; optional Supabase storage, server-only configuration and moderation SQL.
- Vercel build/routing configuration, website types/API/HTTP tests and an optional isolated browser acceptance script.

Public review storage requires the documented owner configuration; new submissions remain pending until approved. Hosted Vercel/database delivery is separate from local and mocked acceptance.

## 0.3.0 — Build tools preview

- Explorer folder menu and Little Home project builder with 40 curated framework/template combinations, language choices and reviewed dependency installation.
- React, Vue, Vite, Angular, Next.js, NestJS, Python, Flutter and React Native/Expo project plans, with project-local Python environments.
- Saved-file runner for 19 language catalog entries, runtime discovery, reviewed compile/run tasks, line input, cancellation and custom interpreter configuration.
- Windows MSYS2/MinGW setup with separately reviewed installation, first-login initialization and GCC package tasks.
- Flutter SDK/device discovery, emulator launch, loopback web preview, hot reload, restart and stop controls.
- Product showcase build-tools catalog and practical workflow documentation.

Language SDKs remain external prerequisites. Actual React creation/install/build and native Node execution were exercised; other framework plans and Flutter protocol handling have fixture coverage. Flutter rendering, every language runtime and installer lifecycle acceptance still require additional environment-specific checks. See [build tools](docs/build-tools.md).

## 0.2.0 — File-aware agent preview

- Dedicated notebook, DOCX, PPTX and PDF readers with bounded source evidence and citations.
- Reviewed text/notebook/document creation and editing, whole-file deletion and exact-byte recovery.
- Required target evidence and filename-safe routing before the agent claims file work.
- Provider request-budget handling, native Groq tool calls and persistent project conversations.
- Static product showcase with product journey, supported-platform guidance and configurable release downloads.
- GitHub source audit, source/website CI, community templates and manual Pages deployment workflow.

PDF mutation currently appends pages; scanned-PDF OCR and legacy `.doc`/`.ppt` operations are not supported. Native fixture acceptance and live-provider rejection/read tests cover different scopes; they do not establish all PRD features or accepted live mutations.

## 0.1.0 — Standalone foundation preview

- Separate Little Code desktop identity on pinned Code-OSS, supplied branding, custom navigation and light/dark themes.
- Ask, Plan, Edit and Agent modes; project intelligence and bounded repository context.
- Groq and local Ollama adapters, local memory and bounded MCP integration.
- Reviewed command/file workflows, Git review, local browser inspection and Windows user setup packaging.
