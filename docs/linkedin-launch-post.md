# LinkedIn launch draft

If VS Code is the first app you open and the last one you close, you’ll probably relate to this.

You’re working on a project. Your editor is open, an AI chat is in another tab, the terminal has a setup command waiting, and you’re copying the same context between them.

That everyday workflow is what got me building **Little Code**. 🚀

It’s a standalone coding workspace built on Code-OSS—the open-source editor foundation behind VS Code—with its own identity and a coding companion called Little Agent.

The familiar editor, terminal and Git workflow are there. Alongside them:

→ Ask questions grounded in your project files.
→ Plan a change, inspect the diff and decide what gets applied.
→ Start React, Next.js, Vue, Python or mobile projects from a menu.
→ Work with notebook cells and supported document formats.
→ Choose Groq Cloud or local models through Ollama.

Building this has involved broken tool calls, provider rate limits and a lot of debugging. Each of those problems has pushed me to think harder about context, reliable tools and keeping the developer in control.

I’ve also been building a React showcase and a screenshot-led documentation hub, so the journey from download to first project is easier to follow.

Little Code is currently a Windows preview, and I’m still improving it.
